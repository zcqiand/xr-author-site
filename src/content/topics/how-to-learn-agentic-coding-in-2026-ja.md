エージェンティックコーディングとは、AI エージェントにキーストロークではなく*タスク*を任せることです。自動補完の次の一行を受け入れる代わりに、「この API にレート制限を追加してテストでカバーして」といった成果物を伝えれば、エージェントが手順を計画し、複数ファイルを編集し、テストを実行し、結果を報告します。今や学ぶべき中核的なエンジニアリングスキルであり、習得が速い人はこれをツールの小技ではなく*ワークフローの規律*として扱っています。

## エージェンティックコーディングとは何か

エージェンティックなコーディングツールは **計画 → 編集 → 検証 → 繰り返し** のループを回します。2026 年時点の主要ツール：

- **Claude Code**（Anthropic）— ターミナルネイティブのエージェント。セッション、CLAUDE.md による永続メモリ、フック、スキル、サブエージェント、サンドボックス付き権限モデルを備えます。
- **OpenAI Codex** — OpenAI のコーディングエージェント。CLI と IDE/クラウドの両方で使え、仕様駆動の長時間タスクに強みがあります。
- **OpenCode** — オープンソースでモデル非依存のエージェント。同じループを、基盤モデルを自分で選んで回せます。
- IDE 組み込みエージェント — 手軽さと引き換えに深さを犠牲にするタイプです。

エージェントを自動補完から切り分けるのは*検証*です。優れたエージェントは自分の差分を読み、テストスイートを実行し、反復します。あなたの仕事はコードを打つことから、**仕様を書き・レビューし・ゲートを管理する**ことへ移ります。

## 実際に機能する学習経路

### 1. コマンドラインと Git の習熟（第 1 週）

エージェントはターミナルで動きます。`git diff`、`git log`、ブランチ、リベースが指に染みていなければ、まずそこを固めましょう。すべてのエージェンティックなワークフローは差分レビューの上に成り立ちます。

### 2. 一つのツールを深く（第 2〜4 週）

Claude Code か Codex を一つ選び、*きちんと*学びます：セッション管理、メモリファイル（CLAUDE.md に何を書くべきか、何を書くべきでないか）、権限モード、フック、カスタムコマンド。チュートリアルを流し見するだけではチャットボットのまま。設定面を学びこそ、それを納品マシンに変えます。

- Claude Code なら：[Claude Code 入門からプロジェクト実践へ](/ja/books/claude-code/) — 最初のコマンドからフック、スキル、サブエージェント、サンドボックス、MCP までを通貫し、二つの実プロジェクトで締めくくります。
- Codex なら：[Codex 入門からプロジェクト実践へ](/ja/books/codex/) — 基礎から OpenAI ツールチェーンでの本番グレードのプロジェクトまで。
- ツールの裏にあるメンタルモデルなら：[図解 AI エージェント](/ja/books/ai-agents/) が計画、ツール呼び出し、メモリ設計を視覚的に解説します。

### 3. 実際のコードベースで練習（第 4〜8 週）

Todo アプリではなく、自分が大切にしているコードベースで。最初は小さく検証可能なタスクを（「このエンドポイントをテスト付きで追加して」）、すべての差分をレビューし、レビュー能力が追いつく範囲でタスクを大きくしていきます。最も重要な規律は **説明できない差分はマージしない**ことです。

### 4. ワークフローを拡張する（第 8 週以降）

2024 年との違いがここに出ます：仕様駆動開発、エージェントが通過すべき CI ゲート、チームの規約を組み込んだカスタムスラッシュコマンド、並列作業のためのサブエージェント。上記の二冊の看板本は、後半をまるごとこれに充てています — ファイルを編集するだけでなく、エージェントとともに*プロジェクト全体*を納品するために。

## よくある失敗

- **プロンプト先行思考。** エージェントは明確な仕様を増幅します。曖昧な仕様は救えません。
- **レビューゲートの省略。** エージェントが書いたからこそ、二度読む必要があります。
- **ツール収集癖。** 浅く六つ学ぶより深く二つ学ぶ方が強い。一つを極めた後のヘッジとして、モデル非依存の [OpenCode](/ja/books/opencode/) があります。
- **検証ループがない。** テストが弱ければ、エージェンティックコーディングは納品を*速く*するどころか遅くします。

## 要約

一つのエージェントを深く学び、レビューゲートに人間を置き続け、実リポジトリで練習し、仕様と CI で拡張する。一冊の本としての道筋が欲しければ、[AI・エージェント開発シリーズ](/ja/series/ai-agents/)が最初のコマンドから納品されたプロジェクトまで運んでくれます。
