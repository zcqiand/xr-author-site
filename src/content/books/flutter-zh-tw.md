心智模型\n\n本節回答一個更根本的問題：界面究竟是怎麼長出來的，並順勢立起本章的兩個心智模型。\n\n回到圖 1-1 的前兩欄，界面在那裡是「被操作的對象」：代碼拿著引用，指哪改哪。這條路走了幾十年，界面一複雜，引用滿天飛，改一處狀態要在好幾個地方手動同步界面。有沒有可能反過來，讓界面自己「算」出來？\n\nFlutter 給出的答案先把結論擺在桌面上：UI=f(state)。用一句話立定義：「界面是狀態的函數：開發者描述給定狀態下 UI 應長什麼樣，框架在狀態變化時負責重新求值並更新界面，不手動操作界面實例。」它與 React 的聲明式同源，但更新單位是 Widget 配置而非 DOM 節點。\n\n    界面 = f(狀態)\n    f =
